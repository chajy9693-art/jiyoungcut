## 저장소에 포함하지 않는 폰트 (직접 설치)

- **NotionHand Community** — 라이선스가 "노션 관련 프로젝트에서만 사용, 단독 배포 금지, 양도 불가"라서 GitHub에 올리지 않습니다(`.gitignore`).
  내 컴퓨터의 이 폴더에 `NotionHand_Community.ttf`를 넣으면 템플릿의 폰트 목록에 자동으로 나타납니다.
  이 폰트에는 한글 글리프가 없어서 영문·숫자만 이 폰트로 표시되고, 한글은 Pretendard로 표시됩니다.
